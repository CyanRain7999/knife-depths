# 飞刀深渊 · Knife Depths

一个可以安装、离线游玩的本地单机像素 Roguelite。Phaser 3 + TypeScript + Vite，没有后端、账号、CDN 素材或联网玩法。

## 开始

需要 Node.js 22.12+（建议 Node 22 LTS 或 24）与 npm。

```bash
npm install
npm run dev
```

打开终端显示的地址，选择角色，点击「开始冒险」。界面采用竖屏小程序游戏风格，支持手机触控和桌面键盘。

```bash
npm test
npm run build
npm run preview
```

生产文件在 `dist/`。Service worker 在生产构建中启用；测试离线和安装请使用 `npm run preview` 或部署后的 HTTPS 站点。不要双击 `dist/index.html`，PWA 需要 HTTP localhost 或 HTTPS。

## 操作与流程

- `A / D` 或 `← / →`：沿底部左右移动。所有武器自动向上投掷。
- `Space`：角色技能；`Esc / P`：暂停。失去页面焦点时输入重置，切到后台自动暂停。
- 手机：方向按钮或在战场内拖动，点技能按钮释放技能。
- 绿色经验与金币落向底部。拾取升级，三选一；每局初始有两次重选。
- 三个武器槽、四个装备槽。新武器满槽要舍弃旧武器；同武器升到 5 级。点击战场下方的武器可以查看和舍弃；装备与被动在「背包」中查看或拆解。
- 每层五个房间，路线只允许走到相邻列。包含战斗、精英、商店、宝箱、事件、祭坛、治疗和 Boss。共八层，击败深渊之心通关。
- 普通战斗停止刷怪后须处理剩余敌人。敌人越过底线会造成伤害；Boss 必须击杀。弹幕和危险区域不会因到计时而消失。
- 装备五品质，随机词条，史诗和传说附加机制。取舍不会占用正在进行的战斗时间。
- 每层诅咒让敌人生命 +8%、对玩家伤害 +4.5%；装备携带的诅咒随卸下移除，事件诅咒通过祭坛消除。某些武器和被动能把诅咒转化为伤害。
- 部分构筑根据持有金币提高伤害，花钱会立即减少加成。商店刷新费用递增。血换装备、强化 Boss、随机事件都需要权衡。
- 胜败均结算余烬；营地永久解锁角色，工坊提供有限的初始生命、幸运和金币成长。前三位角色开局解锁。

第一版内容：**12 角色、36 武器、50 装备、72 被动、26 种敌人、8 Boss、24 事件**。武器有穿透、弹射、返回、分裂、追踪、蓄力、炮台、地雷、光束、上下坠落、异常、距离增伤、连击和处决机制。Boss 各有专属行动与阶段变化。

## GitHub Pages 自动部署

1. 把项目上传到 GitHub，默认分支命名为 `main`。
2. 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 推送到 `main`，或在 Actions 手动运行 **Deploy to GitHub Pages**。
4. 工作流会执行 `npm ci`、测试、构建并部署。站点通常是 `https://用户名.github.io/仓库名/`。

`.github/workflows/pages.yml` 自动把 `VITE_BASE_PATH` 设为 `/仓库名/`，JS、图标、manifest 和 SW 都随仓库目录部署。手动构建子目录也可以：

```powershell
$env:VITE_BASE_PATH = '/knife-depths/'
npm run build
Remove-Item Env:VITE_BASE_PATH
```

```bash
VITE_BASE_PATH=/knife-depths/ npm run build
```

用户主页仓库（`用户名.github.io`）或自定义域名根目录请将工作流 `VITE_BASE_PATH` 改成 `/`。默认本地构建使用 `./`，可放在任意静态子目录。部署整个 `dist`，不要只复制 HTML。

## Windows / Android 安装与离线

这是 **PWA 独立应用**，不是 EXE / APK 安装包。

- Windows：Edge / Chrome 打开部署后的站点 → 地址栏安装图标，或浏览器菜单「安装此站点为应用」。安装后有独立窗口、桌面和开始菜单入口。
- Android：Chrome 打开站点 → 菜单「安装应用」或「添加到主屏幕」。支持平台会安装成独立窗口的 Web App。
- 游戏的「安装应用」按钮在浏览器支持时调用原生安装提示，否则给出手动说明。
- **第一次在线完整打开**，等「离线缓存完成」提示后再断网。所有代码、像素素材与图标均预缓存，后续从独立应用入口即可离线玩。
- 不依赖在线字体、图片、音频或第三方 CDN。音效在本地实时合成。

Vite PWA / Workbox 生成 manifest 与 service worker。内容哈希管理缓存，激活时清理旧缓存。新版本预先缓存后显示更新按钮，**不会强制刷新进行中的远征**；先结算再更新。版本更新不会删除 localStorage 存档。初次访问、安装能力与缓存是否保留取决于浏览器环境。

## 存档

`knife-depths.save.v1` 保存余烬、角色解锁、图鉴、设置、工坊与累计统计。设置页可以导出 / 导入 JSON；导入前显示存档概况并要求确认。损坏存档会回退为初始存档，导入会验证版本、ID、数值与上限。浏览器清数据、隐私模式结束或换域名不共享存档；迁移前请导出。

当前远征不跨刷新保存；切到后台暂停，关闭或刷新会丢失该远征。解锁与结算始终持久保存。存储空间不足会提示导出备份。

## 扩展内容

| 文件 | 职责 |
| --- | --- |
| `src/data.ts` | 全部角色、武器、被动、装备、词条、敌人、Boss、事件配置 |
| `src/types.ts` | 配置字段、机制标签与触发效果类型 |
| `src/engine.ts` | 无 DOM 的可重现战斗模拟、路线、奖励和交易 |
| `src/scene.ts` | Phaser 像素渲染、输入与反馈 |
| `src/main.ts` | 营地、升级、装备对比、商店、事件、结算和 PWA |
| `src/save.ts` | 存档读取、验证与持久化 |
| `src/art.ts` / `scripts/icons.mjs` | 程序化像素图像 / 可重建安装图标 |
| `src/portraits.ts` | 12 位角色的独立 40×44 像素造型与行走帧，营地与战场共用 |
| `src/mini.css` | 竖屏小程序风格界面、触控操作与手机适配 |
| `tests/` | 内容完整性与机制 / 交易 / 战斗回归测试 |

新增已有机制的武器：增加一条 `WEAPONS` 配置。新增被动和装备可组合数值与 `hit / crit / kill / hurt / return / second / freeze / skill` 触发效果；二次伤害不会重复触发命中与暴击，避免无限反馈。新增完全不同的武器轨迹或 Boss 行为需在引擎增加对应处理，不能只加名字。

游戏上限：130 活跃普通敌人、650 玩家投射物、450 敌弹、180 特效、6 炮台。投射物与敌弹使用对象池，Phaser 图像 / 伤害文字复用；命中用空间网格加线段碰撞，避免高速飞刀穿过目标。经验 / 金币过多时合并。较弱设备可关闭粒子、伤害数字和震动。

美术是项目自绘的简单像素形状，没有外部素材版权依赖。界面中文优先，未使用在线字体。
