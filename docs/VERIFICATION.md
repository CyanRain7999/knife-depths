## 复现

```bash
npm install
npm test
npm run build
npm run preview
```

手机画幅检查：开发服务运行时打开 `http://localhost:5173/tests/mobile.html`。该检查页面不会打包进生产站点。

离线验证：按 README 构建 `/knife-depths/` 子目录包，然后 `node scripts/offline-server.mjs`；访问终端中的地址，首次缓存后重新加载一次，再访问 `http://127.0.0.1:4174/__stop_verification` 关闭验证服务器，回到游戏重新加载并开始冒险。验证服务器只绑定本机 127.0.0.1，不属于生产站点。

本环境没有实际安装到 Android 手机或生成 EXE / APK；安装方式为 manifest + service worker 支持的 PWA。8 位 Boss 的行动、阶段及最终层胜利条件通过模拟回归；浏览器手工试玩未逐层完成整局通关。
