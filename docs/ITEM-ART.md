# 物品图标

252 个独立配置的 96×96 SVG 图标：56 把武器、82 件装备、114 个被动，另有 82 个透明装备掉落图像。全部由项目内的绘图代码生成，无外部素材和在线图片依赖。

- 武器按实体结构绘制：刀刃切面、缠绕握柄、钻头螺纹、炮台支架、炸药引线、结晶、护盾、法印等。
- 装备区分皮革、金属、布料、晶石，增加缝线、铆钉、扣带和挂链；套装共享材质主题，各部位保留自己的造型。
- 被动采用八角徽章，把主要效果与联动效果组合成图形，例如冻结与金币、回旋与护盾、毒与火。
- 品质通过独立角标与史诗 / 传说边框表示，保留物品本身的材质配色。

升级、商店、装备对比、背包、武器详情、被动构筑、套装指南和图鉴统一使用新图标。图鉴和被动构筑的图标可点击放大。战场上的装备使用透明图像，继续保留原有品质光柱。

`src/item-icon-art.ts` 是绘图源与完整目录；`scripts/item-icons.mjs` 对照游戏配置导出图像，并检查是否有缺失条目。新增物品时，给对应的 `WEAPON_ART`、`GEAR_ART` 或 `PASSIVE_ART` 增加造型配置。

```bash
npm run art:items
```

`npm run build` 会先自动生成这些文件。SVG 保存在 `public/item-icons/`，使用 Vite base，随 PWA 一起缓存。界面只加载静态图像，绘图代码不会进入游戏运行包；图鉴图片按需加载，战斗渲染继续复用对象池。
